# Info
A Visegrád M3U (avagy V4M3U) egy hatalmas M3U lejátszási lista, a Visegrád Csoport tagjainak a csatornája található itt.


Visegrád M3U (or V4M3U) is a massive M3U playlist featuring channels from the members of the Visegrád Group.


Visegrád M3U (lub V4M3U) to rozbudowana lista odtwarzania w formacie M3U, zawierająca kanały z krajów Grupy Wyszehradzkiej.


Visegrád M3U (neboli V4M3U) je rozsáhlý playlist ve formátu M3U, který obsahuje kanály ze zemí Visegrádské čtyřky.


Visegrád M3U (alebo V4M3U) je rozsiahly zoznam skladieb vo formáte M3U, ktorý obsahuje kanály z krajín Vyšehradskej skupiny.


A projektet kizárólag a közösség finanszírozza, ezért ha tetszik a lejátszási lista, kérjük, támogass minket adománnyal. Ha a projekt máshová kerülne, teljesen megváltoztatjuk a hitelesítési módszert.


This project is solely funded by the community, so if you like the playlist, please donate. If the project ends up anywhere else, we will completely change authentication.


Projekt ten jest finansowany wyłącznie przez społeczność, więc jeśli podoba Ci się ta playlista, prosimy o wsparcie. Jeśli projekt trafi w inne miejsce, całkowicie zmienimy sposób uwierzytelniania.


Tento projekt je financován výhradně komunitou, takže pokud se vám playlist líbí, prosím, přispějte. Pokud by se projekt přesunul jinam, zcela změníme způsob autentizace.


Tento projekt je financovaný výlučne komunitou, takže ak sa vám tento playlist páči, prosím, prispejte. Ak by sa projekt presunul niekam inam, kompletne zmeníme spôsob autentifikácie.
